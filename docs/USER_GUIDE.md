# 使用指南

> 安装、导入音源、播放、外部访问与排错。适用读者：普通用户。
> 开发相关内容见 [文档索引](index.md)。

CPPlayer 是跨平台音乐播放器，支持 Android、Windows、macOS、Linux。

播放器本身不含受版权保护的在线音源。内容能力由插件提供，这点需要先知道。

## 1. 安装

| 平台 | 包 |
|---|---|
| Windows | `CPPlayer-<版本>-win-Setup.exe`（安装后自动建快捷方式）；免安装版 `CPPlayer-<版本>-win-portable.zip` |
| macOS | `.dmg` |
| Linux | `.deb` 或 `.tar.gz` |
| Android | Release 页面的 APK |

应用内置自动更新检查，新版本发布时主动提醒。

## 2. 导入音源

| 步骤 | 操作 |
|---|---|
| 1 | 获取基于 `provider-sdk-kmp` 的音源包（`.zip` 或 `.cpm`） |
| 2 | 首次启动在引导页点「导入音源模块」；或 **设置 → 音源管理** → 右上角「+」 |
| 3 | 导入成功后首个音源自动激活 |

Legacy v1 / Standard v3 旧包不再加载，需作者迁移。

## 3. 功能与入口

| 功能 | 入口 / 说明 |
|---|---|
| 搜索与播放 | 搜索当前激活音源的歌曲，可直接播放或加入队列；不跨音源聚合 |
| 在线扩展能力 | 歌单、专辑收藏、推荐、评论、云盘等按音源声明能力提供；未接入时明确提示不支持 |
| 播放控制 | 点底部播放条展开全屏播放器：播放 / 暂停、切歌、进度拖拽、循环、倍速、逐字滚动歌词 |
| 歌词源 | 播放器内歌词设置，或 **设置 → 歌词来源**：本地边车（`.lrc` / `.ttml`）、AMLL 词库、插件优先级 |
| 音质与缓存 | **设置 → 播放与音质**；桌面端已播放的无损音质自动落盘缓存，支持离线秒播 |
| 音效 | **设置 → 音效**：10 频段 PEQ、风格预设、声道平衡、响度均衡 |
| 快捷键 | 桌面端支持全屏与后台全局快捷键，**设置 → 快捷键** 可改键位 |

## 4. 账号

| 项 | 说明 |
|---|---|
| 入口 | 顶部栏头像，或 **设置 → 音源账号** |
| 登录方式 | 由音源自行实现；扫码、短信、网页登录是否可用取决于该音源 |
| 会话隔离 | 按音源、SDK 账号、凭证版本与设置隔离 |
| 旧数据 | 已有账号数据不会因旧包退役自动删除，也不会按同名迁移 |

## 5. 外部访问与推流

CPPlayer 可作音频流中继，把音频与播控数据输出到局域网或第三方设备（车载、游戏内电台）。

| 步骤 | 操作 |
|---|---|
| 1 | **设置 → 外部访问** |
| 2 | 开启「启用外部访问」，配置端口（默认 64188）与访问令牌 |
| 3 | 选音频输出模式 |

| 模式 | 行为 |
|---|---|
| 本机播放 | 本机正常出声，同时对外提供流 |
| 仅对外提供 | 本机静音，仅供第三方软件拉流 |

接口规范见 [对外集成 API](dev/INTEGRATION_API.md)。

## 6. 局域网同步

| 项 | 说明 |
|---|---|
| 前提 | 多台设备在同一 Wi-Fi 局域网 |
| 开关 | **设置 → 局域网设备**：「在局域网中可见」「自动同步听歌记录」 |
| 能力 | 自动发现对等设备，转移播放进度并双向同步听歌记录 |

## 7. 常见问题

**导入音源后搜索无结果或无法播放**

- 确认音源兼容当前应用版本。
- 点音源管理中的音源卡片，检查是否需要填服务器地址或 API 令牌。
- 需要凭证时按该音源的设置说明操作；当前版本没有通用登录流程。

**如何清理缓存**

- **设置 → 下载与存储**，可分别清理「歌曲音频缓存」「接口数据缓存」「图片封面缓存」。
- 清理缓存不影响用户主动下载的离线音乐。

**多台设备如何同步听歌历史**

- 同一 Wi-Fi 下开启「在局域网中可见」与「自动同步听歌记录」。

**为什么某些功能提示不支持**

- 当前音源未声明或未实现该能力。SDK 契约存在不等于该音源已接入上游。
