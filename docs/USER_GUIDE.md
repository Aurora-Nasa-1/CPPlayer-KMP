# CPPlayer 使用指南

> 面向**使用者**的说明文档。开发者文档见 [`docs/README.md`](README.md)。

CPPlayer 是一款跨平台音乐播放器（Kotlin Multiplatform），Android 与桌面端
（Windows / macOS / Linux）共用同一套播放内核与音源插件系统。

---

## 1. 安装

### 桌面端

- **Windows**：下载 MSI 安装包（`packageMsi` 产物），双击安装。
- **macOS / Linux**：分别提供 Dmg / Deb 安装包。
- 应用内置**更新检查**，新版本发布后会提示升级。

### Android

- 下载 APK 安装（`assembleDebug` / `assembleRelease` 产物）。

> 最低系统要求与具体下载地址见项目发布页。

---

## 2. 首次启动

首次启动会进入引导页，核心步骤是**导入音源模块**：

1. 准备一个音源模块文件（`.cpm` 打包格式，由 Provider 开发者提供）；
2. 在引导页或「设置 → 音源管理」中导入；
3. 导入成功后**首个 Provider 会自动激活**，即可开始搜索与播放。

CPPlayer 自身**不内置任何音乐数据源**，内容能力由音源模块决定。

---

## 3. 音源管理

入口：设置 → 音源管理。

- **导入 / 切换 / 删除**音源模块；切换 Provider 后缓存按 Provider 隔离，互不污染。
- **多音源容灾**：当前 Provider 请求失败时，会自动尝试其他可用 Provider；
  仍失败则回退到旧缓存，尽量保证界面有内容可看。
- **健康状态**：界面顶部的状态指示反映最近请求的综合健康度
  （正常 / 警告 / 异常）。详细诊断见「设置 → 诊断」。

---

## 4. 账号与登录

入口：标题栏头像 / 设置 → 账号。

- 支持扫码或 Cookie 方式登录音源对应的平台账号；
- **多账号隔离**：不同账号的数据（歌单、收藏、评论）互相隔离，
  切换账号不会读到对方的缓存数据；
- 登出会清空本地用户资料与对应缓存。

---

## 5. 日常使用

| 功能 | 说明 |
|------|------|
| 首页 | 今日推荐、常用入口卡片 |
| 曲库 / 歌单 / 专辑 / 歌手 | 云音乐内容浏览，支持歌单增删曲目 |
| 搜索 | 站内搜索，结果可加入队列或歌单 |
| 播放页 | 播放控制、队列管理、歌词、音质选择；「更多」菜单含评论、查看专辑 / 歌手等 |
| 下载 | 离线下载管理 |
| 消息 | 私信与通知（取决于音源支持） |
| 播放设置 | 音质、播放行为等偏好 |
| 渲染调优 | 桌面端渲染性能相关开关 |

**桌面端专属**：

- 原生窗口（阴影 / 缩放 / 贴边吸附 / Aero Snap / 最大化）；
- 返回入口在窗口标题栏，页面内按 `Esc` 也可返回上一级；
- 播放页为全屏体验，会盖过侧栏。

## 6. 本地服务器与流推送

CPPlayer 可以作为**推送方**，把正在播放的音频以 HTTP 流推给外部接收端
（例如游戏内 radio）：

1. 入口：设置 → 本地服务器；
2. **8080** 是 CPPlayer 自己开的流输出端口（支持断点续传语义）；
3. **8420** 是接收端端口，推送走 `/api/v1/play-url` 等标准端点，
   第三方软件按 [集成契约](dev/INTEGRATION_API.md) 即可直接对接；
4. 输出模式可选：
   - **本机声卡**：正常外放，同时对外提供流；
   - **只做服务器（静默模式）**：本机音量恒定为 0，只对外供流。

---

## 7. 缓存与流量

- 读类请求自动走**读透缓存**：命中直接返回，过期自动回源刷新；
- 点赞、评论、登录等**写操作不缓存**，且会自动失效相关读缓存
  （如往歌单加歌后，歌单详情下一次一定是最新数据）；
- 缓存统计（命中 / 未命中 / 回写次数）可在诊断页查看；
- 需要完全关闭缓存时，在播放 / 网络相关设置中关闭即可。

## 8. 常见问题

**Q：导入音源后搜不到东西 / 播放失败？**
先看顶部健康状态与「设置 → 诊断」：若是 `ERROR`，多为音源模块与当前
宿主版本不匹配，更新音源模块或应用后重试。

**Q：切换账号后歌单还是旧的？**
确认切换已生效（登出→登录）；若仍复现，属缓存 bug，请在诊断页清缓存后反馈。

**Q：桌面端窗口贴边吸附 / 拖动不跟手？**
需要使用带 JBR 运行时的安装包（MSI / Dmg / Deb 均内置）；绿色版
（不带运行时）使用系统 JRE 时会回退为自绘窗口。

**Q：外部软件怎么把 CPPlayer 当音源用？**
对接方按 [`dev/INTEGRATION_API.md`](dev/INTEGRATION_API.md) 的 v1 契约
调用 `8420` 端口的标准端点即可，无需额外配置。
