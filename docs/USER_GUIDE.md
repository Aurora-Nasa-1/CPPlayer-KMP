# CPPlayer 使用指南

> 面向用户的快速使用指南。开发者手册请参阅 [开发者文档索引](README.md)。

CPPlayer 是一款现代化跨平台音乐播放器（基于 Kotlin Multiplatform 与 Compose Multiplatform），支持 Android、Windows、macOS 与 Linux。

---

## 1. 安装与启动

### 桌面端 (Windows / macOS / Linux)
- **Windows**：推荐下载 `CPPlayer-<版本>-win-Setup.exe`，安装后自动创建快捷方式；或使用解压即用的免安装便携版 `CPPlayer-<版本>-win-portable.zip`。
- **macOS / Linux**：分别提供 `.dmg` 与 `.deb` / `.tar.gz` 分发包。
- 应用内置自动更新检查，新版本发布时将主动提醒。

### Android
- 下载并安装项目 Release 页面发布的 APK 安装包。

---

## 2. 导入音源与开始使用

CPPlayer 自身不内置任何受版权限制的在线音乐源，内容能力由插件驱动：

1. 获取适合你的音源模块文件（`.zip` 或 `.cpm` 格式，由第三方音源作者提供）；
2. 首次启动时在引导页点击“导入音源模块”，或前往 **设置 → 音源管理** 点击右上角 **「+」** 导入；
3. 导入成功后首个音源将自动激活，即可开始搜索和播放音乐。

---

## 3. 核心功能操作

| 功能 | 入口 / 操作说明 |
|---|---|
| **搜索与播放** | 底部导航“搜索”：支持跨音源搜索单曲、歌手、专辑及歌单，可直接播放或添加至播放队列。 |
| **播放控制与歌词** | 点击底部播放条展开全屏播放器：支持播放/暂停、切歌、进度拖拽、循环模式、倍速播放与逐字滚动歌词。 |
| **歌词源切换** | 在播放器点击歌词设置，或在 **设置 → 歌词来源** 中调整本地边车（.lrc/.ttml）、AMLL 词库与插件优先级。 |
| **音质与缓存** | 前往 **设置 → 播放与音质** 调整试听音质；已播放的无损音质将在桌面端自动进行磁盘流缓存，支持离线秒播。 |
| **音效调节** | 前往 **设置 → 音效** 启用 10 频段参数均衡器 (PEQ)、风格预设、声道平衡与响度均衡。 |
| **快捷键** | 桌面端支持全屏与后台全局快捷键，可在 **设置 → 快捷键** 自定义键位。 |

---

## 4. 账号登录与数据隔离

- 入口：顶部栏头像，或 **设置 → 音源账号**。
- 支持扫码登录、短信验证码、Cookie 导入或网页授权登录（取决于当前激活的音源支持情况）。
- **多账号与多音源隔离**：不同音源及不同账号的歌单、缓存数据相互独立，切换账号或音源后自动隔离。

---

## 5. 本地流输出与外部推送

CPPlayer 可作为音频流媒体中继，将音频与播控数据输出至局域网或第三方设备（如车载、游戏内电台）：

1. 前往 **设置 → 外部访问**；
2. 开启“启用外部访问”，配置端口（默认 64188）与访问令牌；
3. **音频输出模式**：
   - **本机播放**：本机正常出声，同时对外提供流；
   - **仅对外提供**：本机静音，仅供第三方软件拉取串流。

## 6. 常见问题 (FAQ)

**Q：导入音源后搜索无结果或无法播放？**
- 检查音源模块是否兼容当前应用版本；
- 点击音源管理中的音源卡片，检查是否需要在音源配置中填写服务器地址或 API 令牌；
- 若音源需要登录才可试听完整歌曲，请先完成账号登录。

**Q：如何清理缓存释放空间？**
- 进入 **设置 → 下载与存储**，可分别查看并清理“歌曲音频缓存”、“接口数据缓存”与“图片封面缓存”。清理缓存不会影响用户主动下载的离线音乐。

**Q：多台设备如何同步听歌历史？**
- 确保多台设备处于同一 Wi-Fi 局域网下，在 **设置 → 局域网设备** 中开启“在局域网中可见”与“自动同步听歌记录”即可自动完成发现与同步。
