## 正文

大家好，我是 CPPlayer 的开发者，今天在酷安发布 CPPlayer v1.0.0，向大家正式介绍一下这个项目。

CPPlayer 是一款基于 Kotlin Multiplatform 的跨平台音乐播放器：Android 与桌面端（Windows / macOS / Linux）共用同一套播放内核、音源插件系统与 Compose 界面。项目前身是一个 Android 端播放器，后来用 KMP 完成了重构，目标是让手机和电脑获得一致的听歌体验。

【配图 1｜Android 首页 + 桌面端主界面 双平台对比图】

### 一、一套内核，多端运行

- Android 与 Windows / macOS / Linux 共用同一套播放内核与界面代码，功能同步迭代；
- 桌面端提供 Windows 安装包（Velopack）/ Dmg（macOS）/ Deb（Linux），内置 JBR 运行时；
- 桌面端为原生窗口，支持阴影、缩放、贴边吸附、Aero Snap 与系统媒体控制；
- 页面内按 Esc 返回上一级，返回入口集中在窗口标题栏；
- 应用内置更新检查，新版本发布后会提示升级。

【配图 2｜Windows 桌面端播放页（歌词 / 队列）】

### 二、插件化音源系统

- 播放器本体不内置任何音乐数据源，内容能力由音源模块（.cpm 格式）决定，导入后首个 Provider 自动激活；
- 支持同时导入多个音源模块并随时切换，缓存按音源隔离，互不污染；
- 多音源容灾：当前源请求失败时自动尝试其他可用源，仍失败则回退到旧缓存，尽量保证界面有内容可看；
- 界面顶部有健康状态指示（正常 / 警告 / 异常），设置内提供诊断页，可查看缓存命中、请求状态等详细信息，问题可自查。

【配图 3｜音源管理界面 + 顶部健康状态指示】

### 三、播放与账号

- 搜索、曲库、歌单、专辑、歌手页完整覆盖，歌单支持增删曲目；
- 队列管理、歌词显示、音质选择；Android 端支持 Wi-Fi 与移动数据分别设置在线播放音质；
- 离线下载管理；
- 支持扫码 / Cookie 登录，多账号数据互相隔离，登出会清空本地用户资料与对应缓存。

【配图 4｜Android 播放页（队列 / 歌词）】

### 四、本地服务器与流推送

这是 CPPlayer 比较有特色的一块能力，面向有对接需求的用户与开发者：

- 可将正在播放的音频以 HTTP 流推送给外部接收端，例如游戏内 radio；
- 流输出支持断点续传语义（透传 Content-Range / Accept-Ranges）；
- 输出模式可选「本机声卡」或「只做服务器」（静默模式，本机音量恒为 0，只对外供流）；
- 第三方软件可按公开的 v1 集成契约调用 8420 端口的标准端点直接对接，无需额外配置。

【配图 5｜设置页「本地服务器」配置界面】

### 五、缓存与流量

- 读类请求自动走读透缓存：命中直接返回，过期自动回源刷新；
- 点赞、评论等写操作不缓存，并会自动失效相关读缓存，避免读到过期数据；
- 缓存命中 / 回写次数等统计可在诊断页查看，也可在设置中整体关闭。

### 下载与安装

- Android：APK 安装包
- Windows：Setup.exe 安装包（推荐，内置运行时，双击即装完并启动）
- macOS：Dmg ／ Linux：Deb
- 下载地址：见发布页（发帖时补充链接）

### 注意事项

- 首次启动需在引导页导入音源模块后才能搜索与播放；音源模块请自行获取，并遵守对应平台的使用规则；
- 桌面端建议使用安装包版本（内置运行时）；绿色版依赖系统 JRE 时，窗口会降级为自绘实现。
