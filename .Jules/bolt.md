## 2024-05-24 - Avoid un-memoized string formatting in rapid re-composition UIs
**Learning:** In Compose UI, frequently changing states (like playback `positionMs` updating every 10-100ms) will trigger continuous recompositions. Evaluating dynamic properties with expensive logic (like string formatters `formatTimeMs()` or getter functions `val qualityLabel: String get() = ...`) during these rapid recompositions creates intense garbage collection overhead, leading to UI stutter and CPU spikes.
**Action:** Always memoize derived strings for fast-changing states using `remember(state / threshold)` (e.g., `remember(state.positionMs / 1000)` truncates rapid ms updates to 1-second chunks for format re-evaluation) and avoid direct string interpolation (`"${myVar}"`) when `myVar` is already a string.
