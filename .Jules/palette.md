## 2025-02-23 - Dynamic Content Descriptions for Toggle Buttons
**Learning:** Found multiple instances of interactive toggle buttons (like Play/Pause or Shuffle) that use static `contentDescription`s (e.g., `contentDescription = "播放/暂停"`). For screen reader users, a static description for a stateful toggle button is ambiguous because it does not communicate the current state or the result of the action (i.e. whether pressing it will "Play" or "Pause").
**Action:** Always ensure that toggle buttons have dynamic `contentDescription` properties reflecting their current state or intended action (e.g., `contentDescription = if (isPlaying) "暂停" else "播放"`). Apply this proactively across other UI components (like Shuffle and Repeat buttons) to maintain an accessible and localized experience.
