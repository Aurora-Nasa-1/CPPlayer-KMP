根工程以 settings.gradle.kts 声明三个子模块（kmp-pro、app、androidApp），由 build.gradle.kts 集中声明所有 Gradle 插件并以 apply false 延迟加载，各子模块按需引入；依赖版本与库别名集中在 gradle/libs.versions.toml 中，供 kmp_core（Provider 后端）、kmp_ui_app（Compose UI）和 android_app_wrapper（Android 壳）共同消费，形成共享版本基线。子模块之间通过 Kotlin Multiplatform commonMain 暴露的 API 进行通信：UI 层调用 core 的播放控制器与 Provider 抽象，Android 壳负责初始化上下文并将 Compose UI 注入到 MainActivity，从而将后端、界面与平台入口解耦。
