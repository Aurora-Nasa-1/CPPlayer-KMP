模块按 KMP 多目标结构组织：commonMain 存放跨平台共享的 App.kt 根组件、screen/model/component/theme 等 UI 与状态逻辑；androidMain/desktopMain 分别实现 PlatformActions、PlatformFilePicker 及 Theme 的平台差异，并通过 expect/actual 机制被 commonMain 引用。app_bootstrap 子模块负责顶层路由（SetupScreen ↔ MainScreen）与 MusicBackend 状态注入，各 Screen 通过 ScreenModel 持有业务状态并调用 platform 抽象获取系统能力（如文件选择），从而将平台无关的 UI 编排与平台实现解耦。
