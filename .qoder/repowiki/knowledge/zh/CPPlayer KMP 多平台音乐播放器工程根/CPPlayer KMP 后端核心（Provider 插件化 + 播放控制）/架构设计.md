模块基于 Kotlin Multiplatform 构建，`commonMain` 定义领域模型（`model/`）、API 服务（`api/`）、缓存（`cache/`）、Provider 插件体系（`provider/`）、统一音乐源（`music/`）、播放引擎抽象（`playback/`）以及生命周期入口 `MusicBackend`；`androidMain`、`jvmMain`、`desktopMain` 分别提供平台特定的 `PlatformContext`、`SettingsStorage`、`PlatformSupport`、`HttpClientFactory` 与 `ProviderFactory`（Android 用 JNI 动态库、JVM 用二进制/JNI、Desktop 用 JavaFX + MPRIS）。依赖方向严格单向：`MusicBackend` → `ProviderManager`/`ModuleManager` → `BackendProvider`（由外部 zip 模块注入），并通过 `PlatformSupport`/`PlatformContext` 等 expect/actual 隔离平台细节。`MusicBackend` 作为单例门面，组合 `ProviderManager`（活跃 Provider 切换、端口分配、Cookie 隔离）、`ModuleManager`（扫描 modulesDir、导入/删除 zip 模块并解析 `manifest.json`）、`UnifiedMusicSourceImpl`（按 `CPMediaId.providerId` 路由到云 API 或本地源）、`PlaybackControllerImpl`（队列、歌词、收藏、scrobble、自动下一首）以及 `HealthMonitor`，对外仅暴露 `stateFlow`、`unifiedSource`、`playbackController`、`cookieStorage`。`build.gradle.kts` 中声明了 `androidMain.dependsOn(jvmMain)` 的 sourceSet 继承链，使 Android 复用 JVM 层的 OkHttp 客户端实现。
