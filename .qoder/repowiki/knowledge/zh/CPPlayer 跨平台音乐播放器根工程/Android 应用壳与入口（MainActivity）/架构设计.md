本模块是 AGP Android Application 工程，命名空间 `cp.player.app`，仅包含一个入口 Activity 与最小配置：
- `build.gradle.kts` 通过 `alias(libs.plugins.android.application)` 和 `libs.plugins.kotlin.compose` 启用构建插件，声明 compileSdk 36 / minSdk 29 / targetSdk 35，使用 Java 21 编译目标；在 `defaultConfig` 中通过 `ProcessBuilder("git", "rev-parse", "--short", "HEAD")` 注入 `BuildConfig.GIT_SHA`；依赖唯一业务来源为 `implementation(project(":app"))`（KMP 共享模块），以及 `androidx.activity.compose` 与 `kotlinx.coroutines.android`。
- `AndroidManifest.xml` 声明 `INTERNET`、`ACCESS_NETWORK_STATE`、`READ_MEDIA_AUDIO/VIDEO`、`READ_EXTERNAL_STORAGE`（maxSdkVersion 32）等权限，将 `MainActivity` 注册为 `MAIN/LAUNCHER` 入口，并启用 `usesCleartextTraffic="true"` 配合 `res/xml/network_security_config.xml` 允许明文网络流量。
- `MainActivity` 是唯一的平台桥接点：在 `onCreate` 中调用 `initKmpAndroidContext`、`provideAppContext`、`setMediaPermissionRequester`、`MusicBackend.init(context, settings)` 完成 KMP 层初始化，读取 `PackageManager.getPackageInfo` 与 `BuildConfig.GIT_SHA` 填充 `AppVersion`，最后 `setContent { App() }` 渲染共享 Compose UI；生命周期结束时清理静态实例引用。
- 依赖方向单向向外：本模块仅依赖 KMP 共享模块暴露的 `cp.player.kmp.*` 包，自身不持有业务逻辑，职责边界清晰。
