模块按 KMP 多目标结构组织：commonMain 存放 App.kt 根组件、screen/model/component/theme 等跨平台 UI 与业务编排；androidMain/desktopMain 分别提供 PlatformActions、PlatformFilePicker、PlatformShare 的 actual 实现以及 Theme、PagerMouseControl 的平台差异，由 commonMain 通过 expect/actual 引用。app_bootstrap 子模块负责顶层路由（SetupScreen ↔ MainScreen）与 MusicBackend 状态注入，各 Screen 通过同名 ScreenModel 持有状态并调用 platform 抽象获取系统能力，从而将平台无关的界面逻辑与平台实现解耦。
