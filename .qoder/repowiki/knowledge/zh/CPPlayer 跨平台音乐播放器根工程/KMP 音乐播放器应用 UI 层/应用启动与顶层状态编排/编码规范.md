- 所有可观察状态通过 `private val _xxx = MutableStateFlow(...)` 配合 `val xxx: StateFlow<T>` 暴露，读取端使用 `collectAsState` 订阅。
- 对可能失败的外部调用统一使用 `runCatching { ... }.getOrNull()` / `.getOrDefault(...)` 包裹，避免异常上抛破坏 UI 组合。
- 持久化配置项以 `KEY_XXX` 常量命名键，通过 `SettingsStorage` 读写，并同时更新内存中的 `MutableStateFlow` 以保持 UI 即时响应。
- 后台任务统一在 `AppModel.modelScope`（SupervisorJob + Dispatchers.Default/IO）内 `launch`，并通过可取消的 `Job?` 字段（如 `profileRefreshJob`）支持幂等重启。
- Provider 相关操作封装后返回类型安全的 `BackendResult` / `ImportResult`，便捷方法将错误信息暂存到 `lastSwitchError` 等属性供 UI 展示。
