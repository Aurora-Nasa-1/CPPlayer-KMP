## 2024-08-25 - Dynamic Localization for Interactive States
**Learning:** Hardcoded accessibility labels (like "Play/Pause" or "播放/暂停") on multi-state interactive UI elements are bad UX for screen readers. They fail to convey the action that will happen when pressed, especially when state switches rapidly in media players. Furthermore, standard UI elements in KMP apps primarily targeting Simplified Chinese users should always use accurate translations instead of defaulting to English strings (like "Prev" / "Next").
**Action:** When working on interactive multi-state buttons (play/pause, shuffle on/off, repeat modes), always ensure the `contentDescription` dynamically updates to describe the *next action* or the *new state* based on current variables. Always translate these labels to the app's primary localization language (Simplified Chinese) to avoid alienating the user base.
