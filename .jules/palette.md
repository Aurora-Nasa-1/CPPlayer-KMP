## 2024-09-02 - Localize Accessibility Labels

**Learning:** When adding or maintaining accessibility labels (contentDescriptions) in an application whose primary UI language is not English (e.g., Simplified Chinese), ensure that the accessibility strings are localized to match the UI language. English labels mixed with Chinese UI create a disjointed experience for screen reader users.

**Action:** Always verify the target language of the UI when creating accessibility labels and prefer translating hardcoded English labels to the native language.
