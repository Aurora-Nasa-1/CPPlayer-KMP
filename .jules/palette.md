## 2024-05-18 - Localized & Dynamic Accessibility Labels for Player Controls
**Learning:** Found that key playback controls in `MiniPlayer`, `PlaybackControls`, and `DesktopPlayerScreen` used hardcoded English (`Prev`, `Play`) or static (`播放/暂停`) descriptions. For interactive toggle elements, a static label is confusing to screen readers because it doesn't indicate the current actionable state.
**Action:** When implementing interactive UI elements with toggling or multiple states (e.g., play/pause, favorite, repeat modes), always use dynamic `contentDescription` labels that reflect the current state (e.g., `if (isPlaying) "暂停" else "播放"`) to convey the expected action properly. Additionally, ensure all strings are localized to the primary application language (Simplified Chinese) rather than defaulting to English.
