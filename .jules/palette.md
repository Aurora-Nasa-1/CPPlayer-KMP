## 2024-10-06 - Translated Hardcoded 'Clear' Accessibility Label in Search Field
**Learning:** Found an accessibility issue where the 'Clear' button inside the `CpSearchField` component had a hardcoded string `"清空"` for both `onClickLabel` and `contentDescription`. This bypasses localization (specifically using Simplified Chinese when the user might be using English or another locale in the future based on `cpStrings()`). It also violates our localization UX guidelines which mandate using `cpStrings()` for all UI text and accessibility descriptions.
**Action:** Always verify common/reusable UI components to ensure their `contentDescription` and `onClickLabel` attributes pull from the standardized `cpStrings()` object, rather than containing hardcoded literals. Replaced the hardcoded strings with `s.clearSearch` to ensure dynamic localization.
