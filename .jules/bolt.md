## 2024-05-18 - Minimize String Allocation on Continuous Recomposition
**Learning:** In Compose UI patterns like the `PlayerScreen` or `DesktopPlayerScreen`, fast-changing state like `positionMs` is emitted continuously via `PlaybackUiState`. Invoking formatting functions (like `formatTimeMs`) or doing string interpolation directly in the composition leads to heavy and continuous String allocations, causing significant Garbage Collection thrashing and UI stuttering.
**Action:** When displaying fast-changing numeric data as strings (e.g., timestamps), always isolate the state or use `remember` keyed to a truncated or down-sampled value (e.g., `remember(positionMs / 1000)`) to memoize derived variables and avoid unnecessary String object creation in every composition cycle.
