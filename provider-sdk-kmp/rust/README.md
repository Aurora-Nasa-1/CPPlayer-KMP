# cpplayer-provider-sdk

Rust implementation of the CPPlayer `kmp-sdk-v1` provider contract.

It owns the positional Wire codec, typed operation dispatch, session handles,
cancellation, and both native ABIs. A provider implements only the methods it
serves and calls `export_provider!`.

```rust
use cpplayer_provider_sdk::*;

struct MyProvider;

impl MusicProvider for MyProvider {
    fn capabilities(&self, _context: &ProviderContext) -> Vec<&'static str> {
        vec![Capability::SEARCH, Capability::GET, Capability::RESOLVE]
    }

    fn search(&mut self, request: SearchRequest, context: &ProviderContext) -> ProviderResult<TrackPage> {
        let _ = (request, context);
        unsupported()
    }
}

fn create(_context: &ProviderContext) -> Box<dyn MusicProvider> {
    Box::new(MyProvider)
}

export_provider!(create);
```

| Item | Rule |
|---|---|
| Generated files | `src/models.rs`, `src/operations.rs`, `src/vectors.rs`, `provider.h` are generated by `provider-contract/rust.mjs`; do not edit |
| Field names | Author-facing Rust is `snake_case`; wire layout is positional |
| Error type | Author-facing `Failure`; the DTO is `WireFailure` to avoid the name collision |
| Capability switch | `capabilities()` is authoritative; undeclared methods return `Unsupported` |
| ABI | `export_provider!` exports 5 `cpp_*` and 4 JNI symbols |
| Limits | 4 MiB per wire message, 500 items per list; overflow fails instead of truncating |

```powershell
node provider-contract/rust.mjs --check
cargo test --all-targets
```

On Windows, initialize the MSVC environment with `vcvars64.bat` first if
`link.exe` is not on `PATH`. Keep `Cargo.lock` for reproducible builds.
